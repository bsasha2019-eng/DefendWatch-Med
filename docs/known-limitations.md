# Known Limitations & Risks: DefendWatch Med

## 1. Відомі дефекти та обмеження (Known Limitations)

### 1.1. Втрата стану при перезапуску додатку
- **Опис:** Стан екрана (`inputText`, `resultText`, `isLoading`, `isError`) зберігається виключно в пам'яті за допомогою `remember { mutableStateOf(...) }`.
- **Наслідок:** При перезапуску Activity або додатку попередня порада безповоротно втрачається.
- **Шлях вирішення:** Впровадження локального кешу або бази даних Room (заплановано в Лабораторній №3).

### 1.2. Залежність від сесії `adb reverse`
- **Опис:** Команда `adb reverse tcp:8000 tcp:8000` прив'язана до життєвого циклу демона ADB та конкретної сесії емулятора.
- **Наслідок:** Після закриття чи перезапуску емулятора виникає помилка `ConnectException: Failed to connect to /127.0.0.1:8000`. Потрібен повторний ручний виклик команди.

### 1.3. Жорсткість парсингу текстової відповіді ШІ
- **Опис:** Бекенд очікує точний формат тексту `Категорія: ... Порада: ...`.
- **Наслідок:** Якщо модель згенерує синонім (наприклад, `Розділ:` чи `Інструкція:`), категорія перейде в значення `"Невідомо"`.
- **Шлях вирішення:** Перехід на Structured Outputs (JSON Schema mode) в API Gemini або використання Pydantic-based function calling.

### 1.4. Deprecation Warning бібліотеки `google.generativeai`
- **Опис:** Бібліотека `google-generativeai` офіційно застаріла згідно з повідомленням Google.
- **Наслідок:** Виводиться `FutureWarning` при запуску.
- **Шлях вирішення:** Міграція бекенду на новий уніфікований пакет `google-genai`.

## 2. Технічні та безпекові ризики (Risks)

| Ризик | Ймовірність | Вплив | Заходи пом'якшення |
|---|---|---|---|
| **Галюцинації LLM у медичних порадах** | Середня | Критичний | Низька температура (`temperature=0.2`), сувора заборона в промпті ставити діагнози, дисклеймер у UI. |
| **Відсутність інтернету на фронті** | Висока | Високий | У майбутніх ітераціях — додавання локального офлайн-довідника протоколів TCCC. |
| **Витік API-ключа Gemini** | Низька | Високий | Ключ зберігається у файлі `.env`, який внесено до `.gitignore`. Ключ ніколи не передається мобільному клієнту. |
| **Таймаут відповіді ШІ** | Середня | Середній | Каскад швидкісних Flash моделей, таймаут 10с на модель, клієнтський OkHttp таймаут 60с. |
