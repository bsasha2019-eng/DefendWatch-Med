# Requirements: DefendWatch Med

## 1. Реалізовані вимоги (Implemented Features)

### 1.1. Мобільний клієнт (Android)
- **UI на Jetpack Compose:**
  - Заголовок екрана: *"ШІ-Довідник DefendWatch"*.
  - Поле введення тексту (`OutlinedTextField`) з підказкою для опису ситуації.
  - Кнопка надсилання запиту (`Button`) з динамічним станом (`enabled = !isLoading`) та зміною тексту на *"Завантаження..."*.
  - Блок відображення поточного результату (категорія та порада) або тексту помилки червоним кольором.
  - **Блок історії порад (Лабораторна №3):**
    - Відображення списку карток через `LazyColumn` із датою/часом, запитом, категорією та порадою.
    - Автоматичне завантаження історії при запуску екрана (`LaunchedEffect(Unit)`).
    - Автоматичне оновлення списку після кожного успішного отримання відповіді.
    - Лічильник збережених записів у заголовку (`"Історія порад (N)"`).
    - Кнопка «Очистити» для миттєвого видалення всієї історії.
- **Клієнтська валідація:**
  - Перевірка на порожній ввід (`inputText.isBlank()`) перед відправкою з повідомленням *"Будь ласка, введіть опис."*.
- **Мережевий шар:**
  - Retrofit 2.9.0 + Gson Converter.
  - Оновлений інтерфейс `ApiService`: методи `getAiAdvice`, `getHistory`, `clearHistory`.
  - Моделі: `MedicalRequest`, `MedicalResponse`, `HistoryItem`.
  - OkHttpClient з розширеними таймаутами (60 секунд).
  - Налаштування `usesCleartextTraffic="true"` та дозвіл `INTERNET`.

### 1.2. Серверний бекенд (FastAPI)
- **Маршрути (Endpoints):**
  - `GET /` — вітальний статус, посилання на Swagger UI (`/docs`) та історію (`/api/history`).
  - `GET /health` — перевірка працездатності сервісу (`status: ok`).
  - `POST /api/ai-guide` — аналіз опису травми через Gemini та автоматичне збереження в історію.
  - `GET /api/history` — отримання списку збережених порад від найновіших до найстаріших.
  - `DELETE /api/history` — повне очищення збереженої історії.
- **Серверна валідація та моделі:**
  - Pydantic-моделі `MedicalRequest`, `MedicalResponse`, `HistoryItem`.
  - Валідація мінімальної довжини опису (не менше 3 символів, інакше HTTP 400 Bad Request).
- **ШІ-компонент:**
  - Інтеграція з Google Gemini через `google.generativeai` з налаштуванням `transport="rest"`.
  - Fallback-стратегія для перебору швидкісних моделей:
    1. `gemini-flash-latest`
    2. `gemini-2.5-flash-lite`
    3. `gemini-3.5-flash-lite`
    4. `gemini-3.8-flash`
  - Обмеження `max_output_tokens=200`, `temperature=0.2` та таймаут 10 секунд на окрему модель.
  - Парсинг відповіді на поля `category` та `advice`.
- **Автоматизоване тестування:**
  - Повноцінний набір тестів `backend/test_main.py` на базі `pytest` і `TestClient` (ізольовані моки Gemini, перевірка валідації, збереження та очищення історії).
