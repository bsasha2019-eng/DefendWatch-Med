# AI Component: DefendWatch Med

## 1. Призначення ШІ-компонента
AI-компонент призначений для швидкого аналізу неструктурованого текстового опису травми чи симптомів українською мовою та видачі стандартизованої, безпечної, покрокової інструкції з домедичної допомоги відповідно до базових принципів TCCC (Tactical Combat Casualty Care). 

> **Критичне правило безпеки:** ШІ-асистент **НЕ має права встановлювати остаточні медичні діагнози** або призначати специфічні рецептурні медичні препарати. Його завдання — негайні дії для збереження життя та стабілізації постраждалого до прибуття кваліфікованої медичної допомоги.

---

## 2. Системний промпт (Prompt Engineering)

Промпт сформульовано у суворому імперативному стилі з вимогами щодо формату виводу:

```python
prompt = f"""
Ти - тактичний медичний асистент. Тобі надійшов опис ситуації: "{request.description}".
Поверни відповідь СУВОРО у форматі:
Категорія: [Одне слово, наприклад: Кровотеча, Опік, Травма]
Порада: [Коротка інструкція з першої допомоги на 2-3 речення. Без діагнозів!]
"""
```

### Принципи промпту:
1. **Чітка рольова модель:** «Тактичний медичний асистент».
2. **Контроль довжини:** 2–3 речення для мінімізації часу читання у стресовій ситуації.
3. **Маркована структура:** Жорсткі префікси `Категорія:` та `Порада:`, які дозволяють детерміновано парсити відповідь на бекенді.

## 3. Моделі, Fallback та оптимізація швидкодії

Для забезпечення високої швидкодії та стабільності в умовах мобільних мереж впроваджено такі механізми:

### 3.1. Стек моделей та черга Fallback
Через те, що деякі моделі сімейства Gemini (зокрема важкі моделі типу `gemini-3.8-flash` з reasoning-шаром) можуть витрачати до 30–40 секунд на внутрішні роздуми ("thinking tokens"), реалізовано автоматичний каскадний перебір:
1. `gemini-flash-latest` — основна ультрашвидка модель без затримок.
2. `gemini-2.5-flash-lite` — резервна легка модель.
3. `gemini-3.5-flash-lite` — додаткова альтернативна версія.
4. `gemini-3.8-flash` — максимальна версія (якщо попередні недоступні).

### 3.2. Обмеження та параметри генерації
- **`temperature: 0.2`** — низька температура знижує ризик галюцинацій та забезпечує максимальну точність дотримання інструкцій.
- **`max_output_tokens: 200`** — запобігає генерації зайвого тексту та прискорює повернення першого токена (TTFT).
- **`request_options={"timeout": 10}`** — якщо модель не відповідає впродовж 10 секунд, запит негайно переходить до наступної моделі в каскаді.
- **`transport="rest"`** — примусове використання HTTP/REST замість gRPC для уникнення блокування сокетів на платформі Windows.

## 4. Обробка відповідей та аварійний парсинг

Якщо відповідь моделі з якихось причин не містить точних маркерів `Категорія:` або `Порада:`, бекенд застосовує безпечний fallback-парсинг:
- `category` встановлюється в `"Невідомо"`.
- `advice` отримує повний згенерований текст без падіння сервера.
