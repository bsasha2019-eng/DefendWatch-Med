# Project Overview: DefendWatch Med

## 1. Проблема
У польових умовах, зоні бойових дій або під час надзвичайних ситуацій військовослужбовці, парамедики та цивільні особи часто стикаються з травмами, де вирішальне значення мають перші хвилини. Довідники та інструкції часто громіздкі, а доступ до кваліфікованого лікаря може бути відсутнім. Потрібен простий, швидкий та інтуїтивний інструмент, який за коротким описом ситуації надасть базові невідкладні кроки домедичної допомоги без складних термінів.

## 2. Цільова аудиторія
- Військовослужбовці та бійці підрозділів територіальної оборони.
- Волонтери та рятувальники.
- Цивільне населення в умовах надзвичайних ситуацій.
- Особи, які проходять базову підготовку з тактичної медицини (TCCC / MARCH).

## 3. Основний користувацький сценарій
1. Користувач відкриває мобільний застосунок DefendWatch на Android-пристрої.
2. В єдине поле вводу вводить опис проблеми або стану постраждалого (наприклад, *"сильна кровотеча з ноги"*, *"термічний опік руки"*).
3. Натискає кнопку **"Отримати пораду"**.
4. Застосунок відправляє запит на локальний бекенд-сервер, де інтегрована модель Google Gemini.
5. ШІ миттєво повертає структуровану відповідь:
   - **Категорію** надзвичайної ситуації (наприклад: *Кровотеча*, *Опік*, *Травма*).
   - **Коротку покрокову інструкцію** на 2–3 речення (без встановлення медичних діагнозів).
6. Результат одразу відображається на екрані користувача.

## 4. Межі MVP (Scope & Out of Scope)

### Входить до MVP (In Scope):
- Мобільний клієнт на Android (Kotlin + Jetpack Compose) з одним інтерактивним екраном.
- Локальний REST API сервер на FastAPI (Python 3.12).
- Інтеграція з Google Gemini API через оптимізований REST-транспорт і швидкі моделі (`gemini-flash-latest`, `gemini-2.5-flash-lite`, `gemini-3.8-flash`).
- Зв'язок мобільного пристрою/емулятора з сервером через тунель `adb reverse tcp:8000 tcp:8000`.
- Базова валідація вхідних даних (мінімум 3 символи) та обробка помилок мережі.

### Не входить до MVP (Out of Scope):
- Повноцінна база даних користувачів та аутентифікація.
- Постійне збереження історії запитів (заплановано для наступної ітерації).
- Офлайн-робота без підключення до сервера (локальні SLM чи кешовані довідники).
- Складний протокол діагностики або призначення медичних препаратів.
- Голосовий ввід та озвучення тексту (TTS).
