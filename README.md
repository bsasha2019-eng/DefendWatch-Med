# ⚕️ DefendWatch MedSync (Tactical Edition)

Комплексна тактична система медичної евакуації та сортування (Triage), що об'єднує мобільний додаток бойового медика, гібридний ШІ-асистент та автономний апаратний носій даних для бійця. Проєкт розроблено для умов відсутності зв'язку та радіоелектронної боротьби (РЕБ).

## 🚀 Головні можливості

* **Гібридний ШІ-асистент (TCCC / MARCH):**
  * *Офлайн-режим:* Локальна модель для базового медичного сортування та надання критичних порад без доступу до інтернету на "нулі".
  * *Онлайн-режим:* Інтеграція з хмарним Gemini AI для складного фармакологічного аналізу (при наявності супутникового зв'язку на стабпункті).
* **LoRa Радар (868 МГц):** Перехоплення екстрених SOS-сигналів та телеметрії від поранених на відстані до 10 км через підключений USB-радіомодуль.
* **Концепція подвійного QR-коду:**
  * *Базовий рівень (Звичайна камера):* Публічні дані (позивний, група крові).
  * *Розширений рівень (Сканер додатку):* Декодування повної історії поранень та алергій через CameraX API.
* **Безпечна синхронізація (BLE / USB OTG):** Передача Payload-у на смарт-годинник із подальшим переходом носія у режим повного радіомовчання для захисту від пеленгації.

## 🛠 Технологічний стек

* **Мобільний клієнт (Android):** Kotlin, Jetpack Compose, MVVM, Room SQLite, Encrypted DataStore, CameraX.
* **Бекенд:** Python, FastAPI, Uvicorn, Google Generative AI.
* **Апаратна частина (ESP32):** C++, OLED SSD1306 (генерація QR), LoRa SX1276, BLE Server.

## 📁 Структура проєкту

* `/android-app` — Вихідний код Android-додатка.
* `/backend` — API-сервер для онлайн-аналізу та бази даних.
* `/hardware` — Прошивка мікроконтролера смарт-годинника.
