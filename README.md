⚕️ DefendWatch MedSync (Tactical Edition)

DefendWatch MedSync — це комплексна тактична система медичної евакуації та сортування (Triage), розроблена для бойових медиків. Проєкт об'єднує мобільний додаток на Android та бекенд із гібридним ШІ-асистентом для швидкого прийняття рішень в екстремальних умовах за протоколом MARCH/TCCC.

🚀 Головні можливості системи

ШІ-асистент (TCCC / MARCH): Інтеграція з Google Gemini AI для отримання швидких та структурованих порад щодо стабілізації поранених.

Історія порад (In-memory / Local): Збереження попередніх запитів та відповідей для швидкого доступу без повторного звернення до сервера.

Концепція подвійного QR-коду (У розробці): Сканування спеціальних тактичних ідентифікаторів (формат dw://[ID]) для миттєвого отримання медичної картки бійця (група крові, алергії).

Стійкість до втрати зв'язку: Надійна обробка помилок мережі (таймаути, відсутність з'єднання) без аварійного завершення додатку.

🛠 Технологічний стек

Мобільний клієнт (Android):

Мова: Kotlin

UI: Jetpack Compose (Material 3)

Мережа: Retrofit2, Gson

Архітектура: MVVM (у процесі впровадження)

Серверна частина (Backend):

Мова: Python 3.10+

Фреймворк: FastAPI, Uvicorn

ШІ Інтеграція: google-generativeai (Gemini Flash)

Тестування: Pytest

⚙️ Інструкція із запуску (Локальне середовище)

1. Запуск Backend-сервера

Перейдіть у папку бекенду: cd backend

Створіть файл .env та додайте свій ключ доступу: GEMINI_API_KEY=твій_ключ

Встановіть залежності: pip install fastapi uvicorn google-generativeai pydantic pytest

Запустіть сервер:

python -m uvicorn main:app --host 0.0.0.0 --port 8000


(Сервер буде доступний за адресою http://localhost:8000)

2. Запуск Android-додатка

Відкрийте папку проєкту в Android Studio.

Переконайтеся, що запущено емулятор (він автоматично маршрутизує IP 10.0.2.2 на локалхост комп'ютера).

Натисніть Run (Shift + F10).
