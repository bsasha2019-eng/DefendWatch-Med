⚕️ DefendWatch MedSync (Tactical Edition)

Комплексна тактична система медичної евакуації та сортування (Triage), що об'єднує мобільний додаток бойового медика та гібридний ШІ-асистент.

📝 Лабораторна робота №2: Налаштування клієнт-серверної взаємодії

У рамках Лабораторної роботи №2 було успішно налаштовано HTTP-з'єднання між емулятором Android (Jetpack Compose) та локальним сервером FastAPI. Реалізовано надсилання запитів, отримання відповідей від ШІ, а також обробку базових помилок.

🚀 Технологічний стек Лабораторної №2

Клієнт: Android, Kotlin, Jetpack Compose, Retrofit2, Gson.

Бекенд: Python, FastAPI, Uvicorn.

Мережа: Дозвіл INTERNET, usesCleartextTraffic="true", конфігурація доступу до локалхосту через 10.0.2.2.

📊 Результати тестування

1. Успішна взаємодія з ШІ (Запит за протоколом MARCH):
Додаток успішно відправляє запит на бекенд та отримує структуровану пораду від моделі.


2. Обробка порожнього поля:
Валідація на стороні клієнта не дозволяє відправити пустий запит на сервер.


3. Обробка помилки з'єднання (Сервер вимкнено):
У разі відсутності зв'язку з бекендом (відключення сервера Uvicorn), додаток коректно перехоплює виняток і виводить червоне повідомлення про помилку мережі.
