# DefendWatch Med — Мобільний медичний асистент та компаньйон

**Індустрія:** Медицина  
**Лабораторна робота №1:** Налаштування середовища та концепція додатку

## Ідея та концепція
**DefendWatch Med** — це захищений мобільний додаток для зберігання медичної історії, швидкої діагностики та кабельної синхронізації з автономним тактичним смарт-годинником. 

При першому запуску користувача зустрічає фірмовий екран завантаження (**білий щит із хрестом по центру, в який увігнані стріли**), після чого відбувається реєстрація через **Дію** та встановлення особистого пароля, який знає лише власник. Користувач заповнює інформацію про себе, підключає годинник через **USB-кабель** і перетягує дані на пристрій, який автоматично формує на екрані **подвійний QR-код**. Якщо дані змінилися — вони редагуються в додатку та повторно стягуються на годинник по кабелю.

### Технологія подвійного QR-коду
При скануванні QR-коду з екрана годинника через вбудовану камеру нашого додатку медик отримує розширений доступ до повної інформації про людину (електронної медичної книги), прихованої від звичайних сторонніх сканерів.

## Структура додатку (5 основних вкладок)
1. **Інформація про людину:** Головна сторінка з базовими життєвими показниками та кнопкою «Дізнатись більше», яка відкриває розширений список у вигляді повної медичної книги.
2. **Камера (Сканер):** Спеціалізований сканер для зчитування подвійного QR-коду та миттєвого відображення розширеного досьє пацієнта.
3. **ШІ-довідник:** Інтерактивний асистент на базі штучного інтелекту, який веде діалог із користувачем і допомагає діяти в критичних ситуаціях.
4. **Довідник:** Структурована офлайн-база знань та інструкцій із домедичної допомоги.
5. **Акаунт:** Керування власним профілем, безпекою (Дія / Пароль) та меню кабельної синхронізації для оновлення даних на годиннику.

## Основні функціональні вимоги
* Верифікація власника через інтеграцію з **Дією** та захист локальним паролем.
* Ведення базової картки та розширеної електронної медичної книги (Room SQLite).
* Обмін даними зі смарт-годинником через кабель **USB OTG (Serial)** без використання радіоканалів (Bluetooth/Wi-Fi).
* Генерація та декодування **подвійного медичного QR-коду**.
* Консультації в реальному часі через діалоговий модуль **ШІ-довідника** (Gemini API).
